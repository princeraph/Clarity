# Clarity — téléchargement

Clarity est un gestionnaire de tâches personnel, avec un assistant IA qui tourne
sur votre ordinateur. Ce dépôt ne contient que les installateurs ; la page qui
montre l’installation en animation est ici :

**https://princeraph.github.io/clarity-releases/**

## Installer (Windows 10 et 11)

1. Téléchargez
   [Clarity-Setup.exe](https://github.com/princeraph/clarity-releases/releases/latest/download/Clarity-Setup.exe),
   puis ouvrez-le.
2. Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur
   **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Gardez les choix proposés : **Suivant**, **Installer**, puis **Fermer** avec
   « Lancer Clarity » coché.
4. Clarity s’ouvre. Il est aussi dans le menu Démarrer.

**Pourquoi cet avertissement ?** Clarity est une application nouvelle, pas
encore signée avec un certificat payant : Windows ne la connaît pas encore, et
le dit. Si c’est Raphaël qui vous a envoyé ce lien, vous pouvez continuer.

## Mises à jour

Rien à retélécharger : Clarity se met à jour tout seul. Quand une nouvelle
version est prête, le bouton « Mise à jour prête · Redémarrer » apparaît en haut
de la fenêtre ; sinon, elle s’installe la prochaine fois que vous quittez
Clarity.
