Bonjour.
Qu’est-ce qui compte aujourd’hui ?
  1. Ouvrez le fichier téléchargé, Clarity-Setup.exe — dans le panneau des téléchargements de votre navigateur, ou dans votre dossier Téléchargements.
  2. Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. L’installation de Clarity s’ouvre. Gardez les choix proposés : Suivant, puis Installer, puis Fermer, avec « Lancer Clarity » coché.
  4. Clarity s’ouvre. Il est aussi dans le menu Démarrer, et sur le bureau.

Pourquoi cet avertissement ? Clarity est une application nouvelle, pas encore signée avec un certificat payant : Windows ne la connaît donc pas encore, et le dit. Si c’est Raphaël qui vous a envoyé ce lien, vous pouvez continuer.

Mises à jour

Rien à retélécharger : Clarity se met à jour tout seul. Quand une nouvelle version est prête, un bouton Mise à jour prête · Redémarrer apparaît en haut de la fenêtre — un clic, et c’est fait. Si vous ne cliquez pas, elle s’installe la prochaine fois que vous quittez Clarity.
